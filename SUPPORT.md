# Support

ContextHalo supports **Windows 10/11 x64**.

## Bug reports

Use the repository's [bug report form](https://github.com/AaryaMody1301/ContextHalo/issues/new/choose) and include the ContextHalo release/commit, Windows version, provider mode, reproducible steps, and redacted logs when relevant.

## Feature requests

Use the [feature request form](https://github.com/AaryaMody1301/ContextHalo/issues/new/choose). Keep requests focused on the supported Windows target.

## Security issues

Do not publish security-sensitive details in a normal issue. Follow [SECURITY.md](SECURITY.md).

## Protect your data

Never post Gemini or Groq API keys, access tokens, private recordings, sensitive screenshots, personal information, or local credential files in public issues or pull requests.

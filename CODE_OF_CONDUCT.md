# Code of Conduct

ContextHalo is an open-source project intended to be a constructive, welcoming place for collaboration.

## Expected behavior

- Be respectful and professional in issues, pull requests, reviews, and discussions.
- Focus criticism on code, design, documentation, or behavior rather than people.
- Assume good intent, ask for clarification when needed, and provide actionable feedback.
- Respect privacy. Do not post API keys, credentials, private recordings, personal data, or other people's confidential information.
- When reporting security problems, follow [SECURITY.md](SECURITY.md) instead of publishing exploit details in a public issue.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, spam, deliberate disruption, or publishing another person's private information are not acceptable.

## Enforcement

Project maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect the community.

For ordinary project questions, use GitHub Issues. For security-sensitive matters, follow the private reporting guidance in [SECURITY.md](SECURITY.md).
